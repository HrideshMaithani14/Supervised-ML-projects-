# Supervised Machine Learning Mastery: 8 Algorithms Explored 🚀

## 📌 Project Overview
This repository serves as a comprehensive exploration of Supervised Machine Learning. It demonstrates the implementation, evaluation, and comparison of **8 distinct predictive models**, bridging the gap between foundational linear equations and highly optimized ensemble techniques. 

The goal of this project is to showcase a deep understanding of algorithm behavior, hyperparameter tuning, and model evaluation metrics across different architectures.

## 🧠 The 8 Techniques Implemented
This project systematically builds from simple linear models to complex tree-based ensembles:

1. **Linear / Logistic Regression:** The foundational baseline for continuous and categorical predictions.
2. **K-Nearest Neighbors (KNN):** Distance-based algorithmic learning.
3. **Naive Bayes:** Probabilistic classification based on Bayes' Theorem.
4. **Support Vector Machines (SVM):** Finding the optimal hyperplane for maximizing class margins.
5. **Decision Trees:** Non-linear, rule-based splitting techniques.
6. **Random Forest (Bagging Ensemble):** Reducing variance by training multiple parallel decision trees.
7. **Gradient Boosting (Boosting Ensemble):** Sequentially correcting errors of previous models.
8. **XGBoost (Extreme Gradient Boosting):** Highly optimized, scalable, and regularized gradient boosting.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn, XGBoost
* **Data Visualization:** Matplotlib, Seaborn

## 📊 Key Features & Workflow
* **Exploratory Data Analysis (EDA):** Uncovering hidden patterns, distributions, and feature correlations.
* **Data Preprocessing:** Handling missing values, feature scaling (Standardization/Normalization), and categorical encoding.
* **Model Training & Tuning:** Utilizing `GridSearchCV` / `RandomizedSearchCV` to find the optimal hyperparameters for each model.
* **Performance Evaluation:** Comparing models using robust metrics (Accuracy, Precision, Recall, F1-Score for classification OR RMSE, MAE, R² for regression).
